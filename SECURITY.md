# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, through the repository's **Security** tab (*Report a vulnerability*).
Do not open a public issue.

Include the affected version, the steps to reproduce and what happens. You will get an answer within a week.
Fixes ship in a new release, and you will be credited if you wish.

## Supported versions

Only the latest release receives fixes. The desktop application updates itself; a team server is updated by
deploying the new image.

The security design of Chiffrium is described in [docs/security.md](docs/security.md).
